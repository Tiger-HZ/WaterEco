Abstract Automatic segmentation is increasingly used in medical imaging, but many tools require command-line operation and environment setup. TotalSegmentator provides open-source multiorgan segmentation for computed tomography (CT) and magnetic resonance imaging (MRI) data, yet its routine use may be challenging for nontechnical users. Herein, we describe the design, implementation, and functionality of Instant3D, a lightweight, open-source graphical user interface (GUI) frontend for TotalSegmentator. Instant3D was developed in Python using PyQt6. It accepts DICOM folders, NIfTI files, and NRRD files as input and allows users to select regions of interest (ROIs) through a suggestion-enabled interface.
