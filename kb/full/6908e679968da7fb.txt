Large Language Model (LLM)-based code generation tools have gained widespread adoption in software development. The code quality is an important concern that affects the practical usefulness of generated code suggestions. However, comprehensive evaluations of these tools’ code quality remain limited. In this article, we conduct a systematic comparison of five mainstream code generation tools, including GitHub Copilot, Amazon CodeWhisperer, Tongyi Lingma, Tabnine, and Codeium, across five popular programming languages (C, C++, Java, JavaScript, Python). Using 2,613 programming problems from LeetCode, we generated and analyzed 65,325 code suggestions.
