This archive contains the data and MATLAB code supporting the manuscript “Dynamic Resilience of Urban Drainage Systems under Shifting Dominant Constraints” submitted to Water Resources Research. The archive includes rainfall time series, outlet water-quality observations, model input and output data, resilience metric calculations, source data for the figures and tables, and MATLAB scripts used for data processing, resilience metric calculation, post-processing, and visualization. A README file and data dictionary are provided to describe the file structure, variables, units, software environment, and steps required to reproduce the analysis.
