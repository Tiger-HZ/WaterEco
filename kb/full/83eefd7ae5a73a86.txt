This code repository and dataset collection implements a RFR machine learning model for the purpose of predicting ground water levels in the areas of the Adirondack Mountains, New York and San Bernardino, California. The code and data are presented as additional material with the technical note “A Random Forest Regression Workflow for Groundwater Level Forecasting”. In addition to implementing different variations of the RFR model other supporting scripts used in data analysis and feature engineering are also included. The model primarily utilizes meteorological features collected from the ERA5 Land reanalysis dataset and ground water level data obtained from the National Ground-Water Monitoring Network maintained by USGS, presented as a time series in the Excel file format.
