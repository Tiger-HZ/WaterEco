Abstract Remote sensing monitoring of small-lake eutrophication faces challenges such as sparse data, insufficient synergy of multi-source data, and limited model generalization performance. Hence, this study developed a scenario-aware modeling framework for the trophic level index (TLI) by integrating multi-source imagery data from Sentinel-2, GF-1, HJ-2, and PlanetScope, using Dongqian Lake in Zhejiang Province, China as the case study. The cross-sensor prediction accuracy was evaluated using algorithms such as CatBoost Regression (CBR), XGBoost Regression (XGBR), TabPFN Regression (TPFNR), and Linear Regression (LR).
