Abstract This study presents a novel hybrid model called VISCD (Video-Image Streamlined Classification and Detection Model) for vehicle identification, classification, and localization in traffic situations, enabling efficient traffic flow analysis. The proposed system employs a two-stage detection architecture: the first stage uses classical computer vision techniques (OpenCV-based background subtraction and contour detection) for vehicle region proposal and localization, while the second stage uses a hybrid deep learning classifier combining the lightweight design of EfficientNetB0 with the multi-scale feature extraction capabilities of InceptionV3 for vehicle classification. This two-stage paradigm follows the foundational detection framework established by the Region-based Convolutional Neural Network (R-CNN) where region proposal generation is decoupled from classification. Numerous transfer learning models, such as VGG16, VGG19, DenseNet, Inception, ResNet, MobileNet, GoogleNet, and EfficientNetB0, are used to evaluate the model based on key performance indicators, such as F1 score, specificity, sensitivity, accuracy, precision, classification time, and localization time. Experimental results show that the VISCD Hybrid model achieves the highest accuracy of 98.32%. An ablation study confirms that the hybrid model outperforms both the individual networks i.e EfficientNetB0: 94.13%, InceptionV3: 93.13%), with a synergy gain of +4.19%, indicating complementary feature extraction. The model is tested on local population as well as demographic data from the India Driving Dataset (IDD). The hybrid model achieves a classification time of 0.087 seconds per image (~11.5 frames per second, FPS, for the classification stage alone). It should be noted that this figure reflects the classification stage only; when the localization stage is included, the end-to-end throughput of the full pipeline is approximately 0.3 FPS which is sufficient for interval-based traffic flow counting rather than frame-level real-time tracking. Also, the model is tested under synthetic adverse conditions and cross-domain scenario using M6 motorway (UK) video, demonstrating robustness and generalization. The system enables traffic flow monitoring and analysis.
