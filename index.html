项目说明

本知识库面向水生态环境领域研究人员（专家）与管理人员（领导），自动采集、跟踪、整理国内外水生态环境相关知识，并做结构化分类、元数据标注、知识图谱实体抽取与向量化，最终结合大模型/RAG 提供检索与问答能力。

  • 固定访问入口：https://tiger-hz.github.io/WaterEco/（GitHub Pages，永不停机，可收藏）
  • 每日推送：每天自动采集更新，门户按分类 + 时段（近7天→更早）组织；可回看任意历史日期
  • 分类：政策法规与顶层设计 / 标准与技术规范 / 流域治理与工程实践 / 管理实践与制度创新 / 技术产品与监测装备 / 研究文献与调查评估 / 国际与区域动态
  • 质量分级：A 重点 · B 中等 · C 一般；微信公众号内容按阅读量/关注人数过滤低质噪声
  • 区域优先级：浙江 / 杭州最高，其次长三角与重点流域，国外仅收录高度相关且可借鉴内容
  • 智能检索：向量（TF-IDF）+ 关键词（BM25）+ 元数据融合（RRF），支持抽取式问答与主题报告；可外接大模型升级为生成式问答

流水线

采集（政府/微信/学术）→ 归一化去重 → 合并入库 → 质量&水相关度&知识图谱富集 → 静态渲染（门户/推送/档案）→ RAG 检索 → GitHub Pages 自动部署。详细方案见 docs/知识库建设方案.md。
