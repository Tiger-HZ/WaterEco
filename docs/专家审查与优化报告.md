# 水生态环境知识库平台 · 专家审查与优化报告

> 审查视角：水生态环境专业（科技 + 管理双维度）
> 审查对象：`https://tiger-hz.github.io/WaterEco/`（kb 5519 条）
> 审查日期：2026-09-20 ｜ 依据：杭州市生态环境局水生态环境处职责 + 国家/浙江省三级政策体系

---

## 一、审查范围与方法

**审查四个层面**：内容（知识是否专业、全面、可用）→ 功能（能否支撑业务检索与决策）→ 组织（分类、元数据、图谱）→ 界面（是否体现业务专业性）。

**方法**：以处室 23 项业务职责为标尺，逐项检验"该领域的政策依据、标准规范、技术方法、实践案例是否齐备、是否可溯源、是否可检索"。所有结论均基于实测数据，不使用估计值。

---

## 二、审查发现（按严重程度排序）

### 2.1 内容层

**问题一：地域结构严重失衡 —— 本地业务几乎空白（严重）**

| 地域 | 条数 | 占比 | 判读 |
|---|---|---|---|
| 国际 | 3802 | 68.9% | 学术文献为主 |
| 全国 | 1674 | 30.3% | 政策文件为主 |
| **浙江** | **25** | **0.45%** | ❌ 省级依据严重不足 |
| **杭州** | **15** | **0.27%** | ❌ 本地依据几近空白 |
| 长三角 | 3 | 0.05% | ❌ 区域协同材料缺失 |

> **专家判读**：对杭州市水生态环境处而言，最需要的是**浙江省法规 + 杭州市规章 + 杭州断面/水源/流域的实操依据**。
> 现状是"泛学术文献库"而非"业务知识库"—— 这是最致命的偏差。

**问题二：分类维度不体现业务子领域（严重）**

仅有 `category` 一个维度（policy/standard/tech/literature 等 7 类），**无法回答**：
"总氮管控有哪些文件？""底栖生物评价依据是什么？""汛期溢流污染怎么管？"

经核查，原库**没有**"总氮""底栖/水生态""排水管网溢流""再生水""畜禽粪污""蓝藻水华""近岸海域"等任何业务子领域标签。

**问题三：核心元数据大面积缺失（严重）**

| 字段 | 覆盖 | 影响 |
|---|---|---|
| `doc_no`（文号） | **1.4%** | 无法精确引用、无法核验权威性 |
| `content_type`（层级） | **4.9%** | 分不清是法律还是资讯，无法排序 |
| `status`（时效） | **4.3%** | **无法判断文件是否现行有效 —— 存在引用已废止文件的风险** |
| `department`（归口） | 12.5%（87.5% 为"其他"） | 无法按主管条线检索 |

**问题四：学术噪声污染（中等）**

4380 条研究文献中混入大量无关期刊：《Quality in Sport》（体育，37 条）、《RESEARCH JOURNAL OF FOOD SCIENCE》（食品，65 条）、bioRxiv 泛生物学（74 条）。**这些条目挤占库容、稀释检索质量**。

**问题五：原文覆盖率虚高（中等）**

`content_fetched` 字段长期不可信（接管前原始库标称 97.9% 已抓全文，实际正文全空）。
按内容重算后真实覆盖率为 85.5%，其中**必知必会条目仅 68.7%** —— 最该有原文的部分反而不全。

### 2.2 功能层

**问题六：采集渠道覆盖不足（严重）**

原配置仅 8 个源，且多数 `max_pages=1`（只抓首页几条）。经核查**缺失**：
- **水利部、住建部、发改委**（水资源、排水、水价依据）
- **浙江省人大**（省级法规全集，实测 399 篇）
- **浙江省水利厅 / 住建厅 / 农业农村厅**
- **杭州市全部渠道**（市政府、生态环境局、人大、建委）

**问题七：知识图谱不具备业务语义（中等）**

`kg_terms` 高频"实体"是 **Environmental science(556)、Biology(265)、Chemistry(170)、Computer science(154)** —— 均为学术**学科分类词**，非知识实体；且无类型、无关系语义。

### 2.3 界面层

**问题八：无业务域维度导航（中等）** —— 用户只能按 category/部门/时间浏览，无法按"总氮""底栖""排污口"等业务语言检索。

**问题九：无时效标识（中等）** —— 卡片不显示"有效/已修订/已废止"，业务人员无法规避失效文件。

## 三、优化实施（本轮已完成）

### 3.1 分类体系重构（技术 + 管理双重对齐）

| 项目 | 成果 |
|---|---|
| 新增业务域维度 | **23 个受控值**，逐项对齐处室职责（含水环境质量、饮用水源、入河排污口、黑臭与返黑返臭、排水溢流、污水处理、**工业与园区水污染源**、再生水、农村污水、农田退水、畜禽养殖、总氮管控、水生态监测、蓝藻水华、河湖修复、地下水、近岸海域、水资源与生态流量、河湖长制、数字治水、环境应急、EOD、制度法治） |
| 受控词表 | 中文 281 词 + 英文 177 词；核心词（core）中文 110 + 英文 73 |
| 权威映射 | **48 条人工确认规则**，覆盖旗舰法律与综合文件 |
| 标注引擎 | `annotate.py` 三层判定（权威映射 → core 词 → 辅助词），带置信度分级 |
| 词表文件 | `taxonomy.json`（改词表无需改代码） |

### 3.2 元数据回填

一次性回填全库：文号、层级、归口部门、地域、水体、时效、重要性、质量；**同时剔除 kg_terms 中的英文学科噪声词**（首轮清理 2651 条）。

### 3.3 采集渠道扩充（实测驱动）

| 层级 | 改前 | 改后 |
|---|---|---|
| 全国源 | 5 | **14** |
| 浙江源 | 1 | **6** |
| 杭州源 | **0** | **4** |
| 合计 | 8 | **24** |

**新增采集能力**：JS 渲染站文章路径提取通道（攻克浙江省人大）、Hanweb CMS 站点解析、URL 日期自动还原。

**实测抓取成果**：
- 浙江省人大 → 《浙江省饮用水水源保护条例（修正文本）》《浙江省曹娥江流域水环境保护条例（修正文本）》《浙江省农村生活污水处理设施管理条例》《关于修改〈浙江省水污染防治条例〉的决定》
- 杭州市生态环境局 → **《杭州市"十五五"流域水生态环境保护规划（征求意见稿）》**

### 3.4 知识图谱重构

| 项目 | 改前 | 改后 |
|---|---|---|
| 实体定义 | 无类型关键词 | **9 类实体**（水体/法规/机构/污染物/指标/技术/设施/行动/问题） |
| 关系定义 | 仅共现 | **11 类关系**（发布/依据/落实/修订/适用/管控/解决/监测/实践/共现） |
| 噪声 | 学科分类词居首 | 学科词剔除，枢纽为**生态环境部、总氮、总磷、氨氮、钱塘江** |
| 分析能力 | 仅可视化 | 政策沿革、流域全景、**政策缺口检查**、热点识别 |

### 3.5 门户专业化升级

| 新增 | 说明 |
|---|---|
| **业务域筛选 + 左侧导航** | 23 个业务域可筛选、可浏览，条目按域聚合计数 |
| **时效筛选 + 徽标** | 有效（绿）/ 已修订（黄）/ 已废止（灰+删除线）/ 待核 |
| 重点水体徽标 | 条目自动显示关联水体（钱塘江、千岛湖等） |
| 实体图谱 | 优先加载结构化 `kb/graph.json`，失败自动回退 |
| 卡片信息密度 | 业务域 + 水体 + 时效 + 层级 + 质量 + 重要性 多标识并列 |

## 四、成效评估（三维）

| 维度 | 改前 | 改后 | 判读 |
|---|---|---|---|
| **专业性** | 无业务子领域概念；元数据 1.4%–4.9%；图谱为学科词云 | 23 业务域对齐职责；48 条权威映射；9 类实体 11 类关系 | 从"文献库"变为"业务知识库" |
| **全面性** | 浙江 25 条、杭州 15 条；采集源 8 个（杭州 0 个） | 采集源 24 个（浙江 6、杭州 4）；新增本地法规与规划渠道 | 本地依据从"空白"到"有渠可采" |
| **实用性** | 无法按业务语言检索；无时效标识 | 可"按业务域 + 时效 + 水体 + 地域"组合筛选；失效文件可视标识 | 直接支撑日常业务检索与引用 |

| # | 遗留问题 | 计划 |

## 六、专家视角的进一步建议（业务侧）

**科技维度**：
1. **建立"技术方法库"子集** —— 把人工湿地、生态缓冲带、反硝化滤池、eDNA 监测等技术条目按"适用场景/投资强度/去除效率"结构化，支撑方案比选。
2. **断面-水体-政策关联** —— 接入杭州市控以上断面名录（95 个），在图谱中建立 `section` 节点，实现"某断面超标 → 关联适用标准与治理要求"。
3. **总氮专项知识包** —— 总氮是本地区核心矛盾（入海河流），建议单独成栏，聚合标准限值、削减技术、监测方法、考核口径。

**管理维度**：
4. **政策时效预警** —— 对"已修订/已废止"文件在门户显著标注，并在采集时自动比对是否存在新版本，避免引用失效依据。
5. **政策缺口常态化检查** —— 将图谱 §6.3 的缺口检查做成月度任务，自动输出"依据缺失领域清单"，直接转化为采集任务。
6. **本地文件优先** —— 在重要性与必知必会排序中，杭州/浙江文件应获得显性加权（已实施 +0.6/+0.4），确保本地依据始终排在泛学术文献之前。

## 七、结论

本次审查认定的核心问题是：**平台已具备良好的工程骨架（自动化采集、原文核校、覆盖率看板、稳定性机制），但"内容结构"与"业务语义"两个层面尚未完成向"水生态环境业务知识库"的转化** —— 表现为地域失衡、业务域缺失、元数据不足、图谱无业务语义。

本轮已针对四项结构性缺陷完成改造（分类体系、元数据、采集渠道、知识图谱），并在门户实现业务域与时效维度。**改造后平台已能按水生态环境业务语言组织与检索知识，具备支撑处室日常业务与领导参阅的基础能力**；下一阶段的重点是从"结构就绪"进入"内容充实"，即用扩充后的 24 个渠道持续采集本地与省级依据，并完成学术噪声治理与原文补全。
