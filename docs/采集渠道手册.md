## 一、渠道分级原则

| 级别 | 定位 | 收录策略 |
|---|---|---|
| **一级·权威底线** | 法律、行政法规、国家/行业标准、部委规章、省市人大法规 | **必须收全**，作为"必知必会"骨架 |
| **二级·业务依据** | 部委规范性文件、省市规划与实施方案、公报报告 | 按职责域收，重时效性 |
| **三级·实践参考** | 地方做法、技术导则、行业解读、监测数据 | 择优收，重案例价值 |
| **四级·研究支撑** | 学术文献、技术研究 | 只收与业务域强相关者（见 §6 噪声治理） |

> **铁律**：一级渠道宁缺毋滥 —— 链接必须真实可达，文号必须核实；抓不到原文的条目一律标注"暂未收录原文"，绝不编造。

## 五、采集方法（三类站型对应三种通道）

| 通道 | 适用站型 | 实现 |
|---|---|---|
| **A. 锚点解析** | 标准静态站（生态环境部、省级厅局、杭州局、杭州人大、杭州建委） | 抽 `<a href>` + 锚文本，按"路径含日期/文章号 + 标题长度 8–130 + 非导航词"过滤 |
| **B. 源码路径提取** | JS 渲染站（浙江省人大） | 正则提取源码中的文章路径（`tYYYYMMDD_n` / `art_<hash>` / `content_n`），标题取邻近中文串 |
| **C. 政策库检索** | 部委文件聚合（水利部/住建部/发改委等不可直抓者） | 国务院政策文件库按检索词定向抓取，四类（公文/部门文件/公报/解读）分别取 |

**通用要求**：
1. **发布日期自动提取**：`date_from_url()` 从 URL 还原（`t20260817_xxx` → 2026-08-17；`/art/2026/` → 年份兜底）。实测发现列表页普遍不含日期，URL 是最可靠的日期源。
2. **PDF 优先**：详情页内 `.pdf` 附件即原文（标准、规划、条例多以 PDF 挂载），优先下载抽文本。
3. **礼貌限流**：请求间隔 ≥0.3s、超时 20s、重试 3 次、退避上限 20s；设全局运行时限防单站耗尽任务。
4. **去重双键**：URL 规范化 + 标题 sha1（避免长公共前缀标题互相误判）。
5. **相关性门槛**：标题命中强水生态词，**或**摘要命中 ≥2 个 —— 防止"邯郸市城市总体规划"类无关文件混入。

## 六、学术与数据源

| 源 | 用途 | 说明 |
|---|---|---|
| Crossref | DOI 元数据 + 摘要 + PDF 链接 | `api.crossref.org` |
| OpenAlex | 摘要（倒排索引还原）+ 开放获取 PDF | `api.openalex.org` |
| EuropePMC | 生命/环境类文献 | — |
| Unpaywall | 合法 OA 全文 | 需邮箱参数 |
| DataCite | 机构库/数据集摘要 | 兜底 |

**噪声治理（重要）**：实测库内 4380 条研究文献中，出现《Quality in Sport》（体育）、《RESEARCH JOURNAL OF FOOD SCIENCE》（食品）等**与业务完全无关的期刊**。
凡学术文献，须按**业务域相关性**做二次过滤：
- `water_rel`（水相关度）≥ 0.6 且命中至少 1 个业务域 core 词 → 保留
- 否则移入"噪声清单"（先出清单、人工确认后清理，不自动删除）

## 七、渠道健康度巡检（建议每月一次）

```python
# 对每个渠道实测：状态码 / 页面长度 / 可解析文章数
# 判废标准：状态码非 200，或页面长度 < 5KB，或文章数为 0
```

| 巡检项 | 判据 | 处置 |
|---|---|---|
| 状态码 | ≠200 | 连续 2 次失败 → 停用并找替代 |
| 页面长度 | < 5KB（疑似 JS 壳/拦截页） | 改走通道 B 或政策库 |
| 可解析文章数 | = 0 | 解析规则失效 → 更新正则 |
| 新增率 | 连续 3 次新增 0 条 | 检查是否已收全，或页面结构变更 |
| 域名可用性 | 新旧域名并存时 | 双域名探测（如杭州局 epb/sthjj） |
