# 水生态环境知识库 · 建设方案

> 面向对象：水生态环境领域研究人员（专家）与管理人员（领导）
> 建设单位：杭州市生态环境局水生态环境处（牵头）
> 参考范式：[双碳领域知识库](https://tiger-hz.github.io/DualCarbon/)（GitHub Pages 部署）
> 固定访问入口：**https://tiger-hz.github.io/WaterEco/**

---

## 一、建设目标

建立一个**持续运营**的水生态环境领域知识中台，实现：

1. **自动采集与跟踪**：政策法规标准、研究文献、领导讲话、技术产品、实践案例（工程/技术/管理）、专家团队、科研院所与企业等。
2. **团队共享**：知识统一沉淀到项目云盘/知识库，结构化分类与元数据标注。
3. **智能处理**：向量化、知识图谱实体抽取、元数据标注三位一体。
4. **RAG 检索**：向量 + 关键词（BM25）+ 元数据双重检索，提升有效信息命中率，避免漏检高质量信息，也避免引入低质量噪声。
5. **每日推送**：以网页链接形式推送当日重要资讯，按分类 + 时段（由近及远）组织。

## 二、知识范围与优先级

| 维度 | 范围 | 优先级 |
| --- | --- | --- |
| 地域 | 全国（部委） | 中 |
| 地域 | **浙江省 / 杭州市** | **最高** |
| 地域 | 长三角、重点流域（钱塘江、苕溪、运河等） | 高 |
| 地域 | 其他省市先进实践 | 中 |
| 地域 | 国际（高度相关、可借鉴） | 低但精选 |
| 主题 | 地表水生态监管、流域治理、水源保护、入河排污口、断面考核、黑臭水体、美丽河湖、水生态修复、智慧治水 | 核心 |

> 原则：**国内为主、浙江杭州优先、国外仅收录高度相关且具借鉴价值**的内容。

## 三、分类体系（7 类，对齐水生态环境处职责）

分类依据《水生态环境处主要职责》：地表水生态环境监管；拟订水功能区划；水生态环境承载力评估；重点流域污染防治规划；跨界河流断面水质考核；饮用水水源地保护；指导入河排污口设置；配合"五水共治"。

| # | 分类 key | 分类名称 | 核心内容 | 代表来源 |
| --- | --- | --- | --- | --- |
| 1 | `policy` | 政策法规与顶层设计 | 涉水法律法规、国家/省/市规划方案、流域规划、领导讲话（涉水治理） | 国务院、生态环境部、省市政府 |
| 2 | `standard` | 标准与技术规范 | 地表水环境质量标准、排放标准、入河排污口标准、监测/调查/评估技术规范 | 生态环境部、市场监管总局 |
| 3 | `basin_eng` | 流域治理与工程实践 | 重点流域治理、河湖水系连通、黑臭水体整治、水源地规范化、美丽河湖、治水工程案例 | 地方生态环境/水利部门、工程单位 |
| 4 | `management` | 管理实践与制度创新 | 河湖长制、排污许可、断面考核、水生态补偿（新安江模式）、再生水利用、数字治水、入河排污口排查整治 | 各地先进管理实践 |
| 5 | `tech` | 技术、产品与监测装备 | 治理技术、监测溯源、智慧水务/数字孪生、产品装备、新材料 | 科研院所、企业、高校 |
| 6 | `literature` | 研究文献与调查评估 | 学术论文、水生态调查与承载力评估、富营养化/蓝藻、水生态修复研究 | CNKI、万方、期刊、高校 |
| 7 | `intl_region` | 国际与区域动态 | 国际高度相关动态（流域治理、水源保护、水生态修复）+ 兄弟省市/流域亮点、长三角协作 | 联合国/欧盟/US EPA、兄弟省市 |

> 此外，每条知识用 **内容类型（content_type）** 标注其"体裁"：政策文件 / 法规标准 / 领导讲话 / 规划方案 / 研究文献 / 技术产品 / 工程案例 / 管理案例 / 机构专家 / 资讯动态。分类=知识领域，内容类型=内容体裁，两者正交。

| 字段 | 含义 | 取值示例 |
| --- | --- | --- |
| `title` | 标题 | — |

| `date` | 发布日期 | 2026-03-12 |

| `category` | 分类（见上 7 类） | policy / management ... |

## 五、质量等级与微信筛选规则

### 5.1 质量等级（quality）

| 等级 | 含义 | 典型来源 |
| --- | --- | --- |
| **A 重点** | 高质量、必读 | 国家部委/省市政府权威发布；国家级规划法律；重大管理实践；核心研究文献 |
| **B 中等** | 有参考价值 | 厅局级/行业权威；地方实践；一般技术文献 |
| **C 一般** | 资讯动态 | 行业资讯、公众号文章、动态简讯 |

### 5.2 微信内容筛选（防低质噪声）

微信公众号内容按**阅读量 + 公众号关注人数**双维度评估，避免低效低质信息入库：

- 关注人数 ≥ `min_follower`（默认 5000）**或** 阅读量 ≥ `min_read`（默认 2000）；
- 且水相关度 `water_rel ≥ 0.6` 才允许入库；
- 阅读量 ≥ `high_value_read`（默认 10000）自动提级（C→B 或 B→A）；
- 政务号（如"浙江生态环境""杭州发布""中国环境"）视为官方权威，放宽阈值。

> 上述阈值在 `config.json → weixin_filter` 中集中配置，便于随运营情况调整。

## 六、时段窗口（由近及远）

首页与档案页提供统一时段筛选，满足"今天看最新、也能追溯历史"：

- 近 7 天 · 近 1 个月 · 近 3 个月 · 近半年
- 本年度（2026）· 去年（2025）· 前年（2024）· 大前年（2023）
- 近 3 年（2023–2026）· 更早（2022 及以前）

> 近期（默认 180 天）每日生成独立推送页 `push-YYYY-MM-DD.html`，可回看任意一天；更早历史聚合为年度页，避免稀疏单日页。

## 七、智能处理流水线

```
采集层       crawl_gov(政府) · crawl_weixin(微信,含阅读量过滤) · crawl_academic(学术)
   ↓ 归一化/去重 → kb/inbox.json
合并层       merge.py（事件指纹 + URL 规范化去重）→ kb/kb.json（只增不删）
富集层       enrich_importance.py（质量/水相关度/重要性）
             enrich_kg.py（知识图谱实体 kg_terms 抽取）
渲染层       render.py → index.html(SPA门户) · feed.html(无JS回退) · push-*.html · archive.html
检索层       rag.py + rag.html（向量 TF-IDF + BM25 + 元数据融合 RRF，抽取式问答/报告）
部署层       .github/workflows/pages.yml（推送 main 自动发布到 GitHub Pages 固定链接）
```

- **向量化**：中文二元组分词 + TF-IDF 向量，无需第三方依赖，纯标准库实现。
- **知识图谱**：受控词表 + 水生态术语词典规则抽取 `kg_terms`，门户提供实体关系可视化。
- **RAG**：向量匹配 + BM25 关键词 + 元数据（分类/区域/质量/日期）倒数排名融合（RRF），支持部门优先级加权（`prefer_eco`），并支持抽取式问答与主题报告生成；可外接大模型 API 升级为生成式问答。

## 八、每日信息量

- 目标：**每日约 30 条**（结合实际，可多可少，无新动态则少）。
- 质量门槛：默认仅展示 `quality ≥ C`；门户可按质量/区域/分类筛选，确保**不漏高质量、不堆低质量**。

## 九、持续运营机制（知识库不是一次性工程）

| 动作 | 频率 | 负责人 | 交付物 |
| --- | --- | --- | --- |
| 自动采集 + 渲染 + 部署 | 每日 | 定时任务/CI | 当日推送页 |
| 质量与相关性复核 | 每周 | 知识库维护人 | 待更新清单 |
| 过期/重复/冲突治理 | 每月 | 维护人 + 内容负责人 | 合并/废弃建议 |
| 高频问题沉淀为 FAQ | 按需 | 全员 | FAQ 文档 |
| 知识运营月报 | 每月 | 维护人 | 月报 + 知识缺口清单 |

> 提醒：对可能过期、重复、冲突或缺少负责人的文档，标注 `status`（有效/待更新/已废弃/仅供参考），并将更新动作创建为事项分配给维护人。
